## 跨 PR 合同（Q6.1–6.5）

这些缝一旦分叉，后序 PR 会重写前序。实现时按此，不要「顺手合并」。

1. **Temp ledger 文本 vs 落盘（A6.1）**  
   `LedgerDoc.tempLedger(includePath?)` **只造文本 + 1-based `hostLine` 映射**。#68 端口名为 **`TempFilePort`**，只 `write(text) → { checkPath, dispose }`。validation 先 `tempLedger` 再 `write`。report-view 只消费 `tempLedger()`（无 include），不经 Port。禁止在 validation 里再拼一份 temp 文本。

2. **四套行号（A6.2）**  
   - Host line：宿主 0-based（领域词，见 CONTEXT）。  
   - Region / `scanLedger` 的 `startLine`：相对本次扫描文本、0-based。  
   - Temp ledger `hostLine(tempLine1)`：**1-based temp → 1-based 宿主**（现 `buildFenceLedger`）。  
   - CM `doc.line` 与 Problems：1-based；markers：0-based。  
   转换只写在边界（scan→host 在调用方；temp→host 只在 validation/report）。禁止 `hostLine` 有时 0-based。scanner 不吐宿主行号。

3. **`LedgerIndex` 吃原文（A6.3）**  
   `applyVault` / 测试入口吃 **vault 原文 + path**，用 `ledgerKind` 建 `ledgerDoc`，对 `regions` 各 `scanLedger(region.lines.join('\n'))`（若 003 提供 `readonly string[]` overload 则可直接吃 `region.lines`）再并 File facts。删除「先 `ledgerSource()` 再扫」。测试用 `index.setFile(path, rawText)`，不要先拼接。

4. **Clock（A6.4）**  
   生产 `apps/obsidian-plugin/clock.ts` 导出 `Clock` + `systemClock`（`window.setTimeout`）。`FakeClock` 在 `tests/fakes.ts` 实现该接口，`tick(ms)` 推进。#68 第一步引入。#73 对齐 debounce 注入同一接口、**独立 timer map**（`validateTimers` ≠ `alignTimers`）。测试里校验与对齐可共用**一个** FakeClock 时间轴。Fava 就绪继续用 `delay: (ms) => Promise<void>`，**不**改用 Clock。禁止 `vi.useFakeTimers`。

5. **禁逃逸（A6.5）**  
   #68 抽出 `apps/obsidian-plugin/vault-path.ts`：
   `vaultRoot(basePath)`、`resolveInVault(root, vaultRel) → { ok: true; absPath: string } | { ok: false; reason: 'escape' }`。
   `VaultPort.resolveInVault(vaultRel)`（无 `root`，根来自 `vaultRoot()`）与 #74 `resolveLedger` 的适配器都 **调用该模块函数**。不放 `fences.ts`，不放 `bean-check.ts`，fava 不 import `validation.ts`。`resolveLedger` 仍先判 `.bean`/`.beancount`（不对笔记 fence 启 Fava），再 `resolveInVault(root, …)`。Grill A6.5 草稿 `{ ok, absPath } | { escape }` 作废，以 002 签名为准。

过载词：依赖注入边界在计划里叫 **seam**（不要叫 port，以免与 Fava TCP 混淆）。`ledgerSource()` 只保留方法名；领域上说 Ledger text / Temp ledger。
